# Security policy

PocketHost is pre-release software and does not yet execute server workloads.

Report security issues privately to the repository owner rather than opening a public issue. Include the affected commit, Android version, device ABI, reproduction steps, and impact.

Do not test against devices, networks, accounts, or server packages you do not own or have explicit permission to use.

The security baseline is documented in `docs/SECURITY_MODEL.md`.
